Native audio studio AAC + Opus

Record the PS5 audio mix using the console's native encoder. AAC and Opus capture were verified on this console. Disconnect Bluetooth before recording; reconnect when finished.

Live Opus → PC

Open the PC Receiver and select Start listening. Enter its LAN IPv4 address below, disconnect Bluetooth, then start live audio. Stop the stream before reconnecting Bluetooth.

Opus · stereo 48 kHz · 10 ms blocks · UDP · up to two hours per session

Download audioDownload raw packets

AAC downloads use ADTS; Opus downloads use Ogg. Playback depends on your browser or audio player. Raw packets preserve native timestamps. Files remain in /data/hearbridge; starting a new recording changes these links to the latest result.

What this adds
AAC recording128 kb/s · 1024 samples per blockOpus recording128 kb/s · 480 samples per blockNative clock continuityPacket timestamps retained and checkedBluetooth outputUses the connected device's supported codec

Opus blocks contain 10 ms of audio; this is not a measurement of total latency. These encoders create new recording options and live transmission to the PC Receiver. Opus encoder pre-skip is unknown, so exports preserve all captured samples.

Native capture health

Avcap2 · reads without the additional wait loop. Empty reads are normal between PCM blocks; valid silence also counts as progress. An overrun means the library had to reposition its reader.
